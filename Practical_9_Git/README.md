# Practical 9: Version Control with Git & GitHub

## Objective
Study Git fundamentals and commands (init, add, commit, branch, merge, push, pull). Create a GitHub repository and practice collaborative workflows.

## Basic Git Commands Used
1. `git init` - Initializes a new Git repository.
2. `git add .` - Stages all modified files.
3. `git commit -m "Initial commit"` - Commits the staged files.
4. `git branch feature-branch` - Creates a new branch.
5. `git checkout feature-branch` - Switches to the branch.
6. `git merge feature-branch` - Merges branch into main.
7. `git remote add origin <URL>` - Links local repo to GitHub.
8. `git push -u origin main` - Pushes code to GitHub.
9. `git pull origin main` - Fetches and merges latest changes.
